# ConvKit 

**ConvKit** is an Android-based number system converter calculator that allows users to easily and accurately convert between **Decimal, Binary, Octal, and Hexadecimal** — in both directions.

## ✨ Features

- Two-way conversion between all number formats
- Supports **Decimal ↔ Binary ↔ Octal ↔ Hexadecimal**
- Clean and simple Android UI
- Fast and accurate real-time conversion

## 🚀 Installation

Since this app is currently in debug mode, you can install it directly via APK:

1. Download the latest `.apk` file from the [Releases](#) section
2. On your Android device, go to **Settings → Security → Enable "Install from Unknown Sources"**
3. Open the downloaded `.apk` file
4. Tap **Install** and follow the on-screen instructions
5. Open **ConvKit** and start converting!

> ⚠️ Minimum Android version: Android 5.0 (Lollipop) or higher
